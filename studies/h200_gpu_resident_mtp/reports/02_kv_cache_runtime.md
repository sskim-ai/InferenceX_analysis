## Inference

- Server logs directly show FP8 allocation records and disabled CPU/KV offload paths. Their rank-scoped GiB values must not be summed or multiplied into an unsupported cluster-wide physical capacity.

- A profile `usage_prompt_cache_read_tokens` counter is retained as observed evidence, but it is not promoted to a logical-prompt ratio when its scope is incompatible or unverified.
- Do not treat source theoretical prefix reuse as actual server cache residency.
